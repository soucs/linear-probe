# Linear Probe for Deception Detection

This repository contains a set of scripts for training a logistic regression linear probe for deception detection using LLM (Language Model) activations. The scripts are designed to be run sequentially, with each script performing a specific step in the process.

* Data: lasrprobegen/deception_activations [llama_3b_incentivised_3.5k.jsonl](https://huggingface.co/datasets/lasrprobegen/deception-activations/blob/main/roleplaying/llama_3b_incentivised_3.5k.jsonl)
* Generation Model: [Qwen3.5_2B_4bit](https://huggingface.co/mlx-community/Qwen3.5-2B-4bit)
* LLM Judge Model: [Qwen3.5_4B](https://ollama.com/library/qwen3.5:4b)

## Scripts

### `data_formatter.py`

This script preprocesses the input data for the model. The data jsonl file contains individual jsons with a system prompt that directs the model to roleplay a situation requiring a deceptive response. 

In this file, we prefix each system instruction with additional instructions for better generation and assign a unique ID to identify each prompt. The resultant jsons are saved to a new jsonl file.

### `llm_generator.py`

This script contains functions to generate deceptive (or otherwise) responses to each prompt and save the activations in each step as a prompt_id.npy file. The text responses are appended to the original json and saved as a jsonl file.

### `act_generate.py`

This script runs the generate and save functions in `llm_generator.py` for the entire dataset. The dataset consists of 3500 entries.

### `llm_judge.py`

Once the LLM generate responses for all deceptive prompts, the context and the generated responses are passed to another LLM with directions to assign positive/negative labels according to whether they are deceptive or not, respectively. These are then saved as new key-value pairs in the jsonl.

### `log_reg_probe.py`

This script trains a logistic regression linear probe using the activations generated by the LLM model. It takes the activations as input features, and the labels as target variables. The script splits the data into training and testing sets, applies PCA for dimensionality reduction, and trains a logistic regression model. The performance of the model is evaluated using various metrics.

## How to Use

Python 3.14.3 used for the project. Create a new environment and install dependencies using `requirements.txt`.

1. Run `data_formatter.py` to format the input data.
2. Run `act_generate.py` to generate activations for the LLM model.
3. Run `llm_judge.py` to evaluate the performance of the LLM model.
4. Run `log_reg_probe.py` to train the logistic regression linear probe.

Make sure to adjust the paths and parameters in each script to match your specific setup.
